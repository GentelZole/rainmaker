01 — The problem

Mobile money is a Kenyan success story that stops at the border

41.7Mactive M-PESA customers (Safaricom, FY ended Mar 2026)
KES 41.7Tmoved through M-PESA in a single financial year
27.4Mfeature phones still connected in Kenya (CA, Jun 2026)

Kenya has solved domestic value transfer. It has not solved three things that matter to the people at the base of the pyramid:

  • Outbound reach. A Kenyan cannot send value to a Filipino, Nigerian or Indian wallet using the rail already in their hand. Remittance and cross-border corridors stay expensive and intermediated.
  • Currency. Every balance held in the rail is KES — an asset that has lost value against the dollar over any multi-year horizon. There is no self-custodial dollar anyone can hold without a smartphone and a bank account.
  • Device exclusion. Every crypto product of the last decade assumes an app store, a data bundle and a smartphone. 27.4 million devices are excluded by design, not by choice.

Sources: Communications Authority of Kenya, Q4 FY2025/26 Sector Statistics (Jun 2026); Safaricom PLC FY26 results (May 2026).

02 — The product

A Cardano wallet behind a USSD menu

Dial the code. Set a PIN. Receive a Cardano wallet over SMS. From then on, the recipient's phone number is their address — RainMaker resolves phone → Cardano address behind the scenes. Addresses are never typed and never shown in the send flow.

1. User dials *384*225533# — works on any handset, no data required
2. Registers with a 4-digit PIN → HD wallet (CIP-1852, 12-word seed) is generated, AES-256-GCM encrypted, and the seed is delivered by SMS
3. Chooses Send → ADA or DJED → enters recipient phone number or a full Cardano address → amount → PIN
4. Transaction is built and signed server-side, submitted via Blockfrost, confirmed in ~20–60s on Cardano
5. Recipient can sweep the funds into Lace or Eternl at any time with their paper seed phrase — the server never holds an unencrypted key at rest

04 — Why Cardano needs this

The missing primitive is distribution, not another AMM

It is a wallet primitive (RFP A)

RainMaker is a Cardano wallet with a radically different input method. It reaches a device class — the feature phone — that no Cardano wallet, Lace included, can serve. 27.4M devices in one country.

It manufactures net-new stablecoin holders

Every registered user holds a DJED or USDCx balance on Cardano. This is TVL arriving from outside crypto: a Nairobi matatu driver or a Kilifi fisherman who has never held a dollar-denominated asset and has no exchange account.

Two to four transactions per user per month

Register, receive, send, sweep. Each is a Cardano transaction paying network fees. Feature-phone users are high-frequency, low-value — the exact profile that makes a chain's fee revenue real rather than speculative.

Composable by every Cardano app

The address book is a public API: any Cardano app (DEX, lender, payroll tool) can resolve a Kenyan phone number to a verified address and push value into it. RainMaker becomes the last mile for other Cardano products.

05 — Market

Kenya first, because the rails are already there

88.0Mmobile subscriptions, 165% penetration
54.0Mmobile money subscriptions, 101% penetration
568Kmobile money agents (cash-in / cash-out network)
27.4Mfeature phones on network

The cash-in/cash-out agent network that makes M-PESA work is the same network that makes a stablecoin rail usable: an agent takes KES and the user receives DJED, or the reverse. RainMaker does not need to build distribution — it needs to connect to one that already covers the country. Neighbouring markets (Tanzania, Rwanda) share the same USSD aggregator, so expansion is a configuration change, not a rebuild.
