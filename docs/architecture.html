RainMaker Architecture

USSD-to-Cardano Bridge — Feature Phone → Africa's Talking → FastAPI → Cardano

⚠️ Verified against codebase — main.py, ussd_handler.py, wallet_manager.py, cardano_tx.py, sms_service.py, models.py

Security Layers

  • • HTTPS (Let's Encrypt TLS 1.3)
  • • PIN: bcrypt (12 rounds)
  • • Seed: AES-256-GCM encrypted
  • • Rate limit: 30 req/min/phone
  • • Lockout: 5 attempts → 24h
  • • PBKDF2 key derivation (600K)

System Components

  • • FastAPI + uvicorn (Python 3.11+)
  • • Africa's Talking USSD/SMS API
  • • Blockfrost Cardano Preprod
  • • pycardano HD Wallet (CIP-1852)
  • • SQLite → PostgreSQL (prod)
  • • nginx + DuckDNS + SSL

Design Decisions

  • • Phone = wallet address
  • • SMS seed delivery (MVP)
  • • HD wallets auto-generated
  • • CBOR TX (no external builder)
  • • Preprod → Mainnet (Q3 2026)
  • • Bank-grade PIN security
